## PART 1: Admin Panel

The admin panel should have the following sections:

### 1. Dashboard (Overview)
- Total registered users
- Total revenue (all-time, this month, today) — pull from payment records
- Total analyses run (all-time, this month, today)
- Total AI token usage and estimated AI cost (all-time, this month) — using the token_usage_logs table we already have

### 4. Analyses Log

## PART 2: Blog Section (for SEO)

We need a blog to publish content like "CBSE Class 12 Economics Important Topics 2026" etc., to rank on Google and drive organic traffic. This needs two parts: a public-facing blog (for readers/SEO) and an easy admin interface to write and publish posts (for us, non-technical use).

### Public Blog Pages
- Blog listing page at `/blog` — shows published posts as cards (title, featured image, short excerpt, publish date, category tag), paginated
- Individual blog post page at `/blog/[slug]` — clean, readable article layout with proper heading hierarchy (H1 for title, H2/H3 for subheadings), optimized for SEO
- Each blog post page must have proper SEO meta tags: page title, meta description, canonical URL, Open Graph tags for social sharing
- Include a simple "Related Posts" section at the bottom of each post (based on category/tags)
- Blog posts should be crawlable/indexable by Google (no login required, proper sitemap inclusion — add blog URLs to the site's sitemap.xml if one exists, or create one)
- Add a call-to-action within/at the end of blog posts linking back to the main app (e.g., "Analyze your own papers with ToppersTrick →")

### Admin Blog Editor (must be EASY to use — this is important)
- A rich text editor (WYSIWYG) for writing posts — support headings, bold/italic, bullet lists, numbered lists, links, and image insertion directly within the content (not just a plain textarea or raw markdown/HTML input, since I'm not technical and need something visual like a simple version of Google Docs/Notion editing experience)
- Fields needed when creating/editing a post:
  - Title
  - URL slug (auto-generate from title, but allow manual editing)
  - Featured image upload
  - Category/tag (simple dropdown or free-text tags)
  - Short excerpt/summary (for the listing page and meta description)
  - SEO fields: meta title (can default to post title), meta description (can default to excerpt)
  - Main content (rich text editor as described above)
  - Status: Draft or Published
  - Scheduled publish date/time (optional — nice to have, not critical for v1)
- A list view in the admin panel showing all blog posts (draft and published) with quick edit/delete/publish-toggle actions
- Auto-save draft functionality would be valuable so I don't lose work while writing (nice to have, not blocking for v1)

### Technical suggestion
For the rich text editor, please use a well-supported library like TipTap, Quill, or similar — something that outputs clean HTML that can be safely rendered on the public blog page. Please sanitize any user-input HTML properly to avoid XSS issues since this content will be rendered publicly.
