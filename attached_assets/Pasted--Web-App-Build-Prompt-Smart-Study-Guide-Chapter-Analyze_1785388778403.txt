## PROJECT OVERVIEW

Build a full-stack web application called **"Smart Study Guide"** (working name — can be changed) for school and college students in India. Students upload their previous year question papers (last 5 years, same subject), and the app uses AI to analyze chapter-wise question patterns and generate a simple, easy-to-understand study guide in Hinglish (Hindi+English mixed, written in Roman/English script).

**Target users:** School students (Class 10 & 12, CBSE/ICSE/State boards) and college students (university semester exams, courses like B.Com, BA, BSc, etc.)

**Core value proposition:** Instead of reading the entire syllabus, students see which chapters/topics appeared most frequently in past 5 years of papers, get a priority ranking (High/Medium/Low), and receive short Hinglish study notes for high-priority topics — plus a downloadable PDF they can study from.

## TECH STACK REQUIREMENTS

- **Backend:** Node.js with Express.js
- **Frontend:** React (or plain HTML/CSS/JS if simpler — prefer React for better UX) — must be fully mobile-responsive since most users will access via phone
- **Database:** PostgreSQL (use a Node-compatible ORM like Prisma or Sequelize) — needed for user accounts, credit/pack tracking, and analysis history
- **File storage:** Store uploaded PDFs/images temporarily during processing; store generated study-guide PDFs so users can re-download later (use local filesystem storage with cleanup, or a cloud storage bucket if easily available)
- **AI Integration:** OpenAI API using model `gpt-5.4-nano` (cheapest tier, chosen specifically for cost control — do not default to a more expensive model)
- **PDF text extraction:** Use `pdf-parse` or similar Node library for digital/text-based PDFs
- **OCR (for scanned/handwritten papers):** Use `tesseract.js` (Node-compatible OCR) as the default; convert PDF pages to images first if needed (use `pdf-img-convert` or similar)
- **PDF generation (for output study guide):** Use `pdfkit` or `puppeteer` (HTML-to-PDF) — must support clean formatting with headings, bullet points, and highlighted priority topics. Ensure it can render Hindi/Devanagari characters if needed, and Hinglish (Roman script) text without issues.
- **Payments:** Razorpay integration (India-focused, supports UPI) — for the ₹129 pricing pack
- **Authentication:** Simple email or phone OTP-based login/signup

## USER FLOW (STEP BY STEP)

1. **Signup/Login** — simple email or phone-based auth
2. **Category selection** — user selects:
   - "School" or "College"
   - If School: Class (10th/12th) + Board (CBSE / ICSE / State Board — with a dropdown, allow "Other" as free text)
   - If College: Course/Stream (e.g., B.Com, BA, BSc — dropdown + "Other" free text) + Semester/Year
   - Subject name (free text input, e.g., "Accountancy", "Physics", "English")
3. **Upload papers** — user uploads up to 5 years of previous year question papers for that subject (PDF or image format, JPG/PNG accepted). Enforce a hard limit: max 5 files, max 10MB per file, max 15 pages per file.
4. **Processing** — show a loading/progress state while:
   - Text is extracted from each file (digital text extraction first; fall back to OCR if extraction yields little/no text)
   - Extracted text from all years is combined and sent to the AI with a structured prompt (see AI PROMPT section below)
   - AI response (JSON) is parsed and validated
   - A study guide PDF is generated from the parsed data
5. **Results page** — display:
   - A dashboard showing chapters/topics with their frequency count and priority badge (High/Medium/Low, color-coded — e.g., red/orange/green)
   - Hinglish study notes shown inline for High and Medium priority topics
   - An overall exam-strategy tip from the AI
   - A "Download Study Guide PDF" button
6. **Usage tracking** — deduct 1 credit from the user's pack balance per completed analysis. Show remaining credits clearly (e.g., "7 of 10 analyses remaining").
7. **Payment flow** — when a user has 0 credits and tries to start a new analysis, redirect to a purchase page: "₹129 for 10 Study Guide Analyses" via Razorpay. On successful payment, add 10 credits to their account.

## AI INTEGRATION — EXACT PROMPT TO USE

Use the OpenAI API with model `gpt-5.4-nano`. Set `max_tokens` to approximately 3000 for the response. Use the following system and user prompt structure (fill in the placeholders dynamically from user input and extracted text):

### System Prompt:
```
You are an expert academic analyst helping school and college students in 
India prepare for exams using previous year question papers.

Your task: Analyze previous year papers for a specific subject and identify 
chapter-wise/topic-wise patterns to help students focus their study time 
effectively.

Rules:
1. Only use information from the provided papers. Do not guess or invent 
   information not present in the text.
2. Identify chapter/unit names as they would appear in a standard syllabus 
   for this subject, not generic labels.
3. Count how often questions from each chapter appeared across the provided 
   years, and estimate typical marks weightage if marks are visible in the 
   papers.
4. Write study notes in casual, friendly Hinglish (Hindi+English mixed, 
   written in Roman/English script) — simple enough for a school or college 
   student to understand quickly. Not overly formal Hindi, not pure English.
5. If category is "School", use very simple language and an encouraging, 
   supportive tone.
6. If category is "College", use a slightly more mature tone, focused on 
   exam strategy and time management.
7. Output ONLY valid JSON in the exact schema below. No extra text, no 
   markdown formatting, no preamble or explanation outside the JSON.
```

### User Prompt Template:
```
Category: {school_or_college}
Class/Course: {class_or_course}
Board/University: {board_or_university}
Subject: {subject_name}
Number of years provided: {year_count}

Previous year paper content (combined from all years):
{extracted_text}

Analyze this content and return a JSON response with:
1. Chapter-wise frequency count (how many times questions from this 
   chapter appeared across the provided years)
2. Estimated average marks weightage per chapter (if determinable from 
   the text; otherwise use "Not specified")
3. A priority level for each chapter: "High" (appeared in most years / 
   high marks), "Medium" (appeared in about half the years), "Low" 
   (appeared rarely)
4. A short Hinglish study note (60-100 words) for each High and Medium 
   priority chapter — explain what to focus on and common question types 
   (MCQ, long answer, numerical, etc.)
5. One overall exam-strategy tip in Hinglish, appropriate to the 
   School/College tone rule above

Return strictly in this JSON format, with no additional text:
{
  "subject": "string",
  "category": "school | college",
  "years_analyzed": number,
  "chapters": [
    {
      "chapter_name": "string",
      "frequency": number,
      "marks_weightage": "string",
      "priority": "High | Medium | Low",
      "study_note": "string (include only for High/Medium priority chapters)"
    }
  ],
  "overall_strategy_tip": "string"
}
```

**Error handling requirement:** If the AI response is not valid JSON or doesn't match the expected schema, retry the API call once. If it fails again, show the user a friendly error message and do NOT deduct a credit for the failed attempt.
