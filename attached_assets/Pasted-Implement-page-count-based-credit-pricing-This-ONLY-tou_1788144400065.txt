STEP 2 — Page-count helper
In artifacts/api-server/src/lib/extractText.ts, add and export a new function:

  export async function getTotalPageCount(filePaths: string[]): Promise<number> {
    let total = 0;
    for (const filePath of filePaths) {
      const ext = path.extname(filePath).toLowerCase();
      if (ext === ".pdf") {
        let parser: PDFParse | null = null;
        try {
          parser = new PDFParse({ data: fs.readFileSync(filePath) });
          const info = await parser.getInfo();
          total += info.total;
        } catch (err) {
          logger.warn({ err, filePath }, "Could not read PDF page count; counting as 1 page");
          total += 1;
        } finally {
          await parser?.destroy().catch(() => undefined);
        }
      } else {
        total += 1; // single images count as one page
      }
    }
    return total;
  }

This must only call parser.getInfo() (metadata read), never getScreenshot() or any transcription function — it must not trigger vision/OCR calls.

STEP 3 — Tier function
Add and export, in the same file or a suitable shared lib file:

  export function getCreditsForPageCount(totalPages: number): number {
    if (totalPages > 40) return 3;
    if (totalPages >= 20) return 2;
    return 1;
  }

(20-40 inclusive of 20 = 2 credits, >40 = 3 credits, below 20 = 1 credit, matching: <20→1, 20-40→2, 40+→3.)

STEP 4 — Generalize credit deduction/refund
In artifacts/api-server/src/lib/credits.ts, add:

  export async function deductCreditsWith(
    executor: CreditMutationExecutor,
    userId: number,
    amount: number,
  ): Promise<{ batchIds: number[] } | null> {
    const batchIds: number[] = [];
    for (let i = 0; i < amount; i += 1) {
      const result = await deductOneCreditWith(executor, userId);
      if (!result) return null; // insufficient — caller's transaction should roll back
      batchIds.push(result.batchId);
    }
    return { batchIds };
  }

  export async function refundCredits(userId: number, amount: number): Promise<void> {
    for (let i = 0; i < amount; i += 1) {
      await refundOneCredit(userId);
    }
  }

Do not change the existing deductOneCredit, deductOneCreditWith, or refundOneCredit functions — keep them as-is for backward compatibility.
